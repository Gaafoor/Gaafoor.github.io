# Mostafa Ahmed — Robotics Portfolio

Personal site for PhD / master-thesis applications. Built with Astro.

Live: https://gaafoor.github.io/

## Run locally

```sh
export NVM_DIR="$HOME/.nvm"
[ -s "$NVM_DIR/nvm.sh" ] && . "$NVM_DIR/nvm.sh"
npm install
npm run dev
```

Open http://localhost:4321

A push to `main` deploys GitHub Pages via `.github/workflows/deploy.yml`.
